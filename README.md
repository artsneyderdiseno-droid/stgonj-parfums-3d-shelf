# STGONJ Parfums · Infinite 3D perfume shelf

One-screen catalog: an infinite 3D shelf of perfume boxes. The center box spins, and tapping it unfolds a paper sheet with the details.

## ✨ Highlights

- Infinite 3D shelf built with CSS 3D transforms and vanilla JavaScript
- Paper-unfold product detail with price, notes and WhatsApp order button
- Catalog driven by a simple data array
- Privacy policy, terms and 404 pages; zero dependencies

## 🚀 Run locally

No build step. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## 🇪🇸 Español

Catálogo de una sola pantalla: un estante 3D infinito de cajas de perfume. La caja del centro gira y al tocarla se despliega una hoja con el detalle.

Sin compilación. Abre `index.html` en el navegador o sirve la carpeta con `npx serve .`
